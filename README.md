# Zawana Dress Shop

A complete, modern e-commerce website for **Zawana** — an elegant women's dress boutique.

Built with **React**, **Vite**, **React Router**, and **Tailwind CSS**.

## Features

- 🏠 Beautiful homepage with hero, categories, featured products & testimonials
- 🛍️ Full shop page with category filters and sorting
- 👗 Product detail pages with size/color selection
- 🛒 Shopping cart with localStorage persistence (drawer)
- 📱 Fully responsive design
- ✨ Elegant feminine design system (custom Zawana color palette)
- 📄 About & Contact pages

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Project Structure

```
src/
├── components/     # Navbar, Footer, ProductCard, CartDrawer
├── context/        # CartContext (global cart state)
├── data/           # Product data
├── pages/          # Home, Shop, ProductDetail, About, Contact
├── App.jsx
├── main.jsx
└── index.css       # Tailwind + custom styles
```

## Tech Stack

- React 18
- React Router v6
- Tailwind CSS 3
- Vite 5
